1. High-Level Infrastructure Overview

Our entire project is now self-contained inside mdc-robotics-simulation-twin, combining three core technologies: (1) an AnyLogic 8 Multi-Method Simulation Engine (anylogic_model/), (2) a Node.js + Three.js 3D WebGL Digital Twin (digital_twin_app/), and (3) a Python Reinforcement Learning & Streamlit Analytics Stack (rl_models/ & dashboard/).

5. How to Run the Full Stack Locally (All Inside One Repo!)

After cloning or pulling mdc-robotics-simulation-twin, every team member can run and test the entire integrated project in 3 steps:

# TERMINAL 1: Start the 3D WebGL Digital Twin Server (Port 3000)
cd digital_twin_app
npm install
npm start
# Open http://localhost:3000 in your browser to view the 3D Lab & MDC North Campus!

# TERMINAL 2: Train RL Models & Launch the Streamlit Dashboard (Port 8501)
pip install -r requirements.txt
python rl_models/train_qlearning.py
python rl_models/train_ppo.py
streamlit run dashboard/app.py
# Open http://localhost:8501 in your browser to interact with the 5-Tab Analytics Dashboard!

# STEP 3: Open & Run the AnyLogic 8 Model
# Launch AnyLogic 8 -> Open "anylogic_model/MDC_Robotics_Lab_Simulation.alp"
# Run any of the 5 configured Simulation Experiments.

6. Team Git & Collaboration Workflow

  • Branching by Role: When working on improvements, create a feature branch for your module (e.g., git checkout -b jordan/rl-option2, illia/live-dashboard-json, ricardo/alp-experiments, jorge/anylogic-http-bridge) before merging into main.
  • Testing Before Commit:
    • For AI-3D-Robotics-Lab/digital_twin_app: Run npm test to verify all A*, zone, robot clearance, and API unit tests pass.
    • For mdc_robotics_simulation_twin: Run python rl_models/train_ppo.py and verify streamlit run dashboard/app.py launches without errors.
  • Rebuilding Documentation PDFs: Any time a team member updates one of the documentation scripts in mdc_robotics_simulation_twin/docs/, run python docs/generate_team_infrastructure_guide.py (or the corresponding generate_*.py script) to automatically regenerate both the HTML and PDF versions.
