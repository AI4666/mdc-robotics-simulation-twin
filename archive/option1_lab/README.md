# Archive: Option 1 (indoor AI & Robotics Lab)

These files belong to **Option 1** (robots inside the MDC AI & Robotics Lab, Stations A–D). The professor
preferred **Option 2 (campus courier robots)**, so they aren't part of the project anymore. They're kept here,
unchanged, for reference and history. Nothing in the project uses them.

| Folder | Contents |
|---|---|
| `anylogic_model/` | `MDC_Robotics_Lab_Simulation.alp` (lab model), `generate_alp.py`, lab floorplan, old README |
| `docs/` | Lab proposal, integration/bridge guides, team accomplishments, onboarding guide, Zoom agenda, experiment guide, report/slides templates, and the Python scripts that generated them |

The final report and slides (`Final_Project_Report_MDC`, `Presentation_Slides_MDC`) stay in `docs/` because Issue #4
finalizes them there, but they still need to be rewritten for Option 2.

Note: the numbers in the archived report, slides and "Team Accomplishments" (e.g. "82% wait reduction",
"R² = 0.992") were not produced by model runs. Don't reuse them. Use the Option 2 model outputs instead.

To bring a file back: `git mv archive/option1_lab/<path> <original path>`.
