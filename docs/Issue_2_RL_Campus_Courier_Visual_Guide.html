Mathematical Formulation

The Reinforcement Learning Problem

Grounding your Gymnasium environment and policy training directly into AnyLogic's decision loop.

Policy 0
Baseline FIFO
Dispatches immediately to 1 building per trip. Causes frequent half-empty trips and rapid battery drain.
Policy 1
Batching Heuristic
Dispatches only if rover ≥ 60% full, item wait ≥ 45 min, or end of day approach.
Policy 2
Tabular Q-Learning
288 discrete states × 4 actions. Built into AnyLogic and trainable in Python for import via CSV.
Policy 3 • YOUR PPO
Deep RL (PPO)
Neural policy trained with Stable-Baselines3. Continuous state inputs, optimizing non-linear tradeoffs.
👁
Observation Space (St)
288 Discrete States for Q-Table • Continuous for PPO

The supervisory agent observes 5 core features every 5 minutes:

  • Sorted Mail Ready (4 bins): 0 units, < 2 units, < 5 units, ≥ 5 units.
  • Free Idle Rovers (3 bins): 0, 1, or 2+ available robots.
  • Average Battery Level (3 bins): < 40%, < 70%, ≥ 70%.
  • Time of Day Block (4 bins): < 10:00, < 12:00, < 14:00, ≥ 14:00.
  • Class Change Soon (2 bins): 1 if within 10 min of class change; else 0.
// Exact state index matching AnyLogic:
state_idx = (((ready * 3 + free) * 3 + batt) * 4 + block) * 2 + soon;
⚙
Action Space (At)
4 Discrete Dispatch Actions
Action 0
WAIT (Hold Standby)
Do nothing now. Let incoming sorted mail pile up to form fuller, high-efficiency batches.
Action 1
SEND_ONE (Dispatch Single Rover)
Picks fullest building outbox, fills leftover slots with nearest neighboring buildings, and launches 1 robot.
Action 2
SEND_ALL (Fleet Surge)
Dispatches every eligible idle robot to clear major mailroom backlog spikes.
Action 3
CHARGE (Opportunistic Top-off)
Routes the lowest-battery idle rover to the mailroom charging pad before congestion hits.
🏆
Multi-Objective Reward Function (Rt)
Balances on-time deliveries, queue latency, and fleet battery health
// 1. Decision Step Reward (Calculated every 5 minutes):
R_step = delivered_units - (0.02 × waiting_units × 5) - (0.5 × Δbattery_pct_used)

// 2. End-of-Day Carryover Penalty (At 17:30 shift end):
R_end = - (0.5 × items_left_in_mailroom)
+ Deliveries:

Direct reward for putting package units into building lockers.

- Waiting Queue Penalty:

Penalizes sorted mail sitting idle in the mailroom instead of being delivered.

- Energy & Rollover:

Prevents unnecessary empty trips and heavily penalizes undelivered mail left overnight.
